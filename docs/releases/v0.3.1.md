후속작과 용어를 맞췄습니다. 그림·무비는 v0.3과 같습니다.

## 변경 사항

- 후속작 「돌격!! 패미컴 워즈 VS」와 같은 세계관이라 두 게임에 같이 나오는 용어를 하나로 맞췄습니다.
  - 공격 헬기 → 전투 헬기, 기관총탑·감시탑·통신탑 → 기관총 타워·감시 타워·통신 타워, 시추탑 → 채굴 타워
  - 따르기 모드 → 따라오기 모드, 방어막 → 배리어, 드럼통 → 통
  - 메뉴: 확대/축소 → 줌, 유닛 설명의 능력치 → 상태
- 대사 몇 줄의 번역을 다듬었습니다.

## 적용 방법

1. `G8WJ_KPatch_v0.3.1.zip`을 받아 풉니다.
2. 풀린 폴더에 일본판 원본 이미지를 넣고 `패치하기.bat`을 더블클릭합니다(원본을 `패치하기.bat` 위에 끌어다 놓아도 됩니다).
3. 같은 폴더에 `Totsugeki!! Famicom Wars (Korean).iso`가 생깁니다.

지원 형식(ISO·GCM·CISO·WIA·WDF·GCZ)과 오류 메시지는 동봉한 `README.txt`(첨부 `README_KO.txt`와 같음)를 참고하세요.
