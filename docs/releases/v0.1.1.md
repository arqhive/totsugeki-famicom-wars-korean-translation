그림 4장을 다시 그리고 디스크 배너를 한글화했습니다. 대사·메뉴·폰트는 v0.1과 같습니다.

**원본 일본판에 적용하는 전체 패치입니다.** v0.1 한글판 ISO에 덧씌울 수 없습니다.

## 변경 사항

- 디스크 배너 그림(게임큐브 메뉴, Dolphin·Nintendont 게임 목록에 나오는 로고)을 한글로 바꿨습니다.
- 타이틀 로고를 다시 그렸습니다. 원본에 있던 ™ 표시를 되살렸습니다.
- 건강·안전 경고 화면과 버튼 안내 문구 그림을 다시 그렸습니다.
