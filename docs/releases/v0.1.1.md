그림 4장을 다시 그리고 디스크 배너를 한글화했습니다. 대사·메뉴·폰트는 v0.1과 같습니다.

## 변경 사항

- 디스크 배너 그림(게임큐브 메뉴, Dolphin·Nintendont 게임 목록에 나오는 로고)을 한글로 바꿨습니다.
- 타이틀 로고를 다시 그렸습니다. 원본에 있던 ™ 표시를 되살렸습니다.
- 건강·안전 경고 화면과 버튼 안내 문구 그림을 다시 그렸습니다.
- 덤프 형태와 상관없이 적용되는 패처로 바꿨습니다.

## 지원 형식

| 원본 형식 | 결과 |
|---|---|
| ISO, GCM | ISO |
| CISO, WIA, WDF, GCZ | ISO (동봉한 wit으로 변환 후 적용) |
| RVZ, NKit | 지원 안 함 (ISO로 바꾼 뒤 적용) |

## 적용 방법

1. `G8WJ_KPatch_v0.1.1.zip`을 받아 풉니다.
2. 풀린 폴더에 일본판 원본 이미지를 넣고 `패치하기.bat`을 더블클릭합니다(원본을 `패치하기.bat` 위에 끌어다 놓아도 됩니다).
3. 같은 폴더에 `Totsugeki!! Famicom Wars (Korean).iso`가 생깁니다.

자세한 방법과 오류 메시지는 동봉한 `README.txt`(첨부 `README_KO.txt`와 같음)를 참고하세요.
